Máquina para dibujar

Instrucciones

1GL

Instrucciones:

  • 000, Borrar todo
  • 001, Subir
  • 010, Bajar
  • 011, Izquierda
  • 100, Derecha
  • 101, Borrar
  • 110, Pintar
  • 111, Pintar todo

2GL

Instrucciones:

  • BOT, Borrar todo
  • SUB, Subir
  • BAJ, Bajar
  • IZQ, Izquierda
  • DER, Derecha
  • BOR, Borrar
  • PIN, Pintar
  • PIT, Pintar todo

3GL

Instrucciones:

  • BORRAR;
  • PINTAR;
  • BORRARTODO;
  • PINTARTODO;
  • MOVER Dirección;
    Posibilidades:
    MOVER IZQUIERDA
    MOVER DERECHA
    MOVER ARRIBA
    MOVER ABAJO;
  • PINTAR Dirección;
    Posibilidades:
    PINTAR IZQUIERDA
    PINTAR DERECHA
    PINTAR ARRIBA
    PINTAR ABAJO;
  • BORRAR Dirección;
    Posibilidades:
    BORRAR IZQUIERDA
    BORRAR DERECHA
    BORRAR ARRIBA
    BORRAR ABAJO;
  • REPETIR InstruccionDirección Número;
    Ejemplos:
    REPETIR MOVER ABAJO 5;
    REPETIR MOVER IZQUIERDA 3;
    REPETIR PINTAR DERECHA 4;
    REPETIR BORRAR IZQUIERDA 3;
  • CUADRADO Número
    Ejemplo:
    CUADRADO 4;
    CUADRADO 7;
